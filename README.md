# Ratu Melody Visualizer PRO

Downloads for Ratu Melody Visualizer PRO, a Windows app for making music videos with audio visualizers and synced lyrics.

Get the installer from the [latest release](https://github.com/Satria155/ratu-melody-visualizer-releases/releases/latest). The app downloads its data files from this repository by itself.
